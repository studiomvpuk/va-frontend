# Fonts

`GeneralSans-Variable.woff2` goes here.

Download from https://www.fontshare.com/fonts/general-sans (free, SIL Open Font
License). It is not committed because redistributing a font file through a repo
is a licensing question nobody wants to answer later — the download is one step
in the setup docs instead.

Until it is present the app falls back to the system sans, which is legible but
loses the rounding the brand personality depends on (PRD §3.2).
